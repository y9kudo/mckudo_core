# Version Arthas · 1.0.0-Arthas-dev.3

Development build dated **2026-10-15**. Created by y9kudo, MIT. Core, bundled OMConnect and OMVectorize report the same build version.

## Main changes

- Agent Center renders received blocks in a local WebGL 3D view with optional Minecraft textures/models from a local client JAR or resource pack. It exposes route steps, program waypoints, targets, gaze, entities and protected regions, with bounded scanning and a snapshot-age indicator.
- The visual program builder supports resource goals, movement, registered skills, sequence/parallel groups, if/else, repeat and bounded until. Its block and JSON editors share one portable document; JavaScript export uses the new `agent.runProgram` API.
- The README and dashboard/program guides explain setup, ownership of each layer, asset loading, execution behavior and validation limits.
- Version discovery uses official launcher metadata. Experimental older-vanilla profiles adapt legacy world/inventory packets, and the 1.20.4 recipe reader handles its actual field names. [Version lab](https://github.com/y9kudo/mckudo_core/blob/v1.0.0-Arthas-dev.3/docs/VERSION-LAB.md).

- Added a focused fresh-spawn Nether trial and a persistent exploration-distance goal. Its live completion is evaluated separately from configuration checks.
- Added clearer contribution instructions and issue forms for reproducible bug reports and feature proposals.

## Run this checkout

```powershell
npm.cmd ci
npm.cmd run dashboard
```

Open http://127.0.0.1:4180. The default server target is local Java 1.21.1 on port 25565, offline authentication. [Dashboard setup](https://github.com/y9kudo/mckudo_core/blob/v1.0.0-Arthas-dev.3/docs/DASHBOARD.md) · [Program reference](https://github.com/y9kudo/mckudo_core/blob/v1.0.0-Arthas-dev.3/docs/PROGRAMS.md).

Build archives with `npm.cmd pack --ignore-scripts` from the root and from `packages/omconnect`. Game texture archives, worlds, logs and auth caches are runtime data and are excluded from packages. This document describes the checkout; publication and downloadable release assets are separate steps.

## Validation boundaries

The build passes 579 regression tests, TypeScript checks, English text checks and clean installation of both source packages. Browser checks cover nested editing, item search, textured 3D rendering, ray picking and waypoint editing on desktop and mobile viewports. A live Java 1.21.1 Survival trial completed a browser-applied resource/crafting program and a separate exact-waypoint walk. [Detailed validation and evidence](https://github.com/y9kudo/mckudo_core/blob/v1.0.0-Arthas-dev.3/docs/results/arthas-dev3-validation-2026-10-15.md).

Native gameplay profiles remain 1.21/1.21.1. Experimental protocol profiles are not blanket support for every historical Minecraft action. A bounded resource trial does not establish full-game autonomy. Stable 1.0.0 remains gated on a verified empty-inventory run ending in an own Ender Dragon victory.
