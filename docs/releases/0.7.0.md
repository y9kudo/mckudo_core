MCKudo Core **0.7.0** — библиотека принятия решений и автоматизации Minecraft: Java Edition. В комплект входит самостоятельный **KudoConnect 0.7.0** с **KudoVectorize**. Автор **y9kudo**, лицензия **MIT**.

### Основные изменения

- **Evidence Memory:** память условий отказа и общий проверяемый опыт группы. KudoConnect передаёт код ошибки и наблюдаемые стартовые предусловия; MCKudo разрешает повтор при изменении участвующих фактов. Временные помехи не превращаются в постоянный общий запрет.
- **Полёты и 3D:** объёмные водные маршруты KudoVectorize, запас воздуха, расчёт коридора для элитр, раскрытие крыльев/ракета/посадка с серверными подтверждениями. Creative-полёт следует разрешению сервера.
- **Стройка:** импорт `.nbt`, `.litematic/.litematica`, Sponge `.schem` v2/v3 и безопасного подмножества `.schematic`; подбор площадки, постановка отдельных блоков со свойствами и проверка состояния. Ограниченный журнал отказов декоративных ячеек препятствует повторным циклам. Пример пяти совместных строителей включён.
- **Хранилища:** обнаружение сундуков, двойных сундуков, бочек и шалкеров, перенос заданного количества, поиск по табличкам, сортировка по категориям и подпись хранилищ.
- **Выживание и бой:** выбор доступного дерева по классу, экономия старших кирок, повторный подход к луту, безопасный отход, подготовка еды/кровати/станций. Защита взгляда от эндерменов, прогноз падения с попыткой воды или жемчуга, лестницы и ближняя фаза сидящего дракона.
- **Панель и SDK:** обзор чанков, параметры агента, задачи и импорт схем; простой API/JSON-миссии, типы и примеры. Физические действия одного клиента выполняются последовательно.
- **Платформа:** Microsoft Device Code Auth, серверные меню, подтверждённая посадка/выход из транспорта, граф модовых машин с внешними исполнителями. Книга рецептов индексируется по запросу и использует данные сервера.
- **Проверки выпуска:** строгий TypeScript в CI, установка обоих архивов в отдельное приложение без Mineflayer, проверка состава пакетов и ссылок документации.

### Подтверждения

Локально на Windows / Node v24.19.0 прошли **436 автоматических тестов**, TypeScript, проверка упаковки и установка архивов. Публикация выполняется workflow после CI Windows/Linux × Node 22/24.

На vanilla Java 1.21.1 отдельно проверялись полёт с предоставленными элитрами/ракетой, сортировка сундуков и бой подготовленного Avery07 с драконом. Подтверждены смерть дракона и 14 собственных попаданий; это не прохождение с пустым инвентарём.

Последний кооперативный прогон пяти агентов завершён без полного алмазного набора у любого участника. Большая пользовательская схема построена частично. Эти результаты опубликованы вместе с успешными проверками.

### Границы версии

Нативные игровые профили — **Java 1.21 / 1.21.1**. Экспериментальная Java 26.3 не прошла устойчивый игровой цикл и не объявляется поддержанной. Microsoft-модуль имеет автоматические проверки, но настоящий вход владельца лицензии требует отдельного испытания. Самостоятельное управление лодкой, произвольные модовые машины и полное прохождение от спавна до дракона ещё не подтверждены. Четыре следующих метода интеллекта описаны как проекты и не входят в реализованный API.

### Установка

Скачайте `mckudo-0.7.0.tgz` либо `kudoconnect-0.7.0.tgz` из Assets и установите нужный пакет:

```powershell
npm.cmd install .\mckudo-0.7.0.tgz
# Для самостоятельного клиента:
npm.cmd install .\kudoconnect-0.7.0.tgz
```

Требуется Node.js 22+. `SHA256SUMS.txt` содержит контрольные суммы. Публикация в npm в этот выпуск не входит. Кэш авторизации, миры, `data/`, сырые игровые журналы и локальные настройки не включаются.
