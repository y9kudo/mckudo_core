# OvermindMC 1.0.0-Arthas-dev.2 — Version Arthas

Development prerelease of **OvermindMC**, its independent **OMConnect** client and **OMVectorize** spatial layer. Created by **y9kudo**, licensed under **MIT**.

## Included in this preview

- Optional C/Node-API computation: bounded static ground A*, signed VarInts, packet framing and an explicit dense-inference API. JavaScript adapters and the existing planner handle unsupported native cases.
- Survival recovery: supported stairs out of caves, conservative cave reconnaissance, visibility before approaching blocks, usable workstation checks and safer placement on interactive supports.
- Persistent confirmed placement ownership, including duplicate server notifications and furnace lighting changes; bounded food and navigation recovery policies.
- Campaign checkpoint/resume, heartbeat, learning evidence, action journals and local status/profiling commands.
- The OvermindMC naming migration, version/profile API, PPO/discrete SAC experiments, physical headless environments and an opt-in RL control bridge from the Arthas development branch.

Package versions, runtime labels and public declarations are synchronized to `1.0.0-Arthas-dev.2` / `v1.0.0Arthas-dev.2`.

## Validation and scope

The release workflow requires the complete automated suite, types, examples, archive checks and installed-package smoke tests on Windows/Linux with Node 22/24. Linux jobs additionally compile and require the C kernel checks. Local verification includes **561 tests** with the compiled native module.

Prior live evidence remains labeled with its original development version. Survival testing confirmed starter equipment, a shield and iron tools; an ownership-memory repair is disclosed in that diagnostic continuation. **An unassisted campaign from spawn to an own Dragon victory is not yet certified.** This preview is not stable Arthas 1.0.0, and the C migration remains partial.

## Install the GitHub build

Download an archive from this release's Assets, then run:

```powershell
npm.cmd install .\overmindmc-1.0.0-Arthas-dev.2.tgz
# Or install the independent client:
npm.cmd install .\omconnect-1.0.0-Arthas-dev.2.tgz
```

Node.js 24 is recommended. Installing a tarball still resolves its dependencies through npm; this release does not publish the packages to the npm registry.

The archives contain portable source, declarations, examples and documentation. The optional C module must be built for the target platform using the native build guide. Local binaries, worlds, runtime journals and account caches are excluded. `SHA256SUMS.txt` records the installation archives' hashes.

For source development and tests, clone the `v1.0.0-Arthas-dev.2` Git tag, run `npm.cmd ci`, then `npm.cmd test` and `npm.cmd run test:types`.
