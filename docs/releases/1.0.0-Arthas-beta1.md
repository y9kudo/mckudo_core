# OvermindMC 1.0.0-Arthas-beta1

Created by **y9kudo**. Beta development build; this is not the stable autonomous-completion milestone.

The navigation executor now maintains velocity between compatible walking spans, uses bounded footprint-checked lookahead, and stops an obsolete route on a server position correction. A short-lived, one-use route handoff avoids repeating the kernel's search when its observed execution conditions remain valid.

Combat execution has moved into a dedicated reactive controller. It reassesses range, occlusion, shield direction, weapon choice, spacing and critical opportunities without waiting for a completed aim animation or a separate blocking guard action. Sending an attack no longer counts as observed damage for pursuit progress. PvP still requires explicit authorization through the application's combat policy.

Navigation failure memory now records directed transitions and excludes transient state changes. Existing schema-one network weights and replay samples can be loaded; destination-wide failure bans are discarded during migration.

OMConnect responds to common ping packets during configuration and play, fixing a LAN login stall observed during this update. Root package, standalone client, vector identity and declarations use the same version. YourMind retains its own `alpha1.0` version.

See the [behavior and audit guide](../BETA1-NAVIGATION-COMBAT.md) and [verification evidence](../results/arthas-beta1-validation-2026-10-15.md). Full autonomous Dragon completion, a controlled live PvP benchmark and broad-version movement equivalence remain acceptance work.
