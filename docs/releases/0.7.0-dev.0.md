MCKudo Core — библиотека принятия решений и автоматизации Minecraft Java. KudoConnect — самостоятельный клиент, включённый в ядро и выпускаемый отдельно. Автор **y9kudo**, MIT.

Это **предварительная сборка 0.7.0-dev.0**. Последний стабильный релиз — 0.6.0; эта сборка не заявляет завершённого автономного прохождения игры.

### Что добавлено

- **KudoVectorize**: проверка объёма тела и коллизий, ограниченный асинхронный поиск водных маршрутов в 3D, запас воздуха и математический предиктор шага элитр. Отдельные импорты `mckudo/vectorize` и `kudoconnect/vectorize`.
- Microsoft Device Code авторизация через протокольную библиотеку: отдельный кеш, события входа без токенов, отмена и защита от позднего подключения. Offline-вход сохраняется.
- Простые водные миссии `swim` и API `agent.swimTo(position)`.
- Чтение серверных GUI, выбор уникального пункта и отслеживание ревизии окна. Посадка в лодку/вагонетку и выход требуют подтверждения сервера.
- Машинный граф рецептов с жидкостями, катализаторами, побочными продуктами и проверкой результатов исполнителя. Формат JSON и пример доступны разработчикам адаптеров модов.
- Журнал фактического прогресса кампании, отдельные состояния смерти, остановки и неподтверждённой победы.
- Отдельные квоты наблюдений для деревьев, руд и станций; подготовка локальной шахтной лестницы; подготовка инструментов перед необязательным запасом мяса и навигационный отход при угрозе.

### Проверки и оставшиеся задачи

Локально прошли **355/355 тестов**, строгая проверка TypeScript и установка обоих архивов в отдельное приложение. Создание этого релиза разрешено workflow только после проверок Windows/Linux × Node.js 22/24.

На offline Java **1.21.1** подключение, короткий наземный маршрут и расчёт водного пути на реальных чанках прошли; коррекций позиции на коротком маршруте — 0. После исправления восприятия агент с пустым инвентарём добыл дерево, изготовил верстак и деревянную кирку. При продолжении с этой киркой добыл 2 булыжника. Подход к отдельным каменным блокам остаётся нестабильным.

Две короткие попытки профиля до дракона завершились гибелью на первом этапе. Полное прохождение, финальные титры и победа над драконом **не подтверждены**. Реальный Microsoft-вход, Realms и плавание ещё требуют игровых испытаний. Автопилот элитр, управление лодкой и настоящий JEI-экспортёр не реализованы; машинные исполнители подключаются отдельно. Нативные игровые профили ограничены Java 1.21/1.21.1; интеграция Realms зависит от версии сервера.
