# OvermindMC 0.6.0: Training, peace mission and mechanic

OvermindMC — Decision-making library. OMConnect Connected to server, Gets peace and does things. The application creates a client, connects brain and sets the tasks. Author of both libraries — **y9kudo**, licence MIT.

## Quick Panel Launch

From a folder `mckudo_core`, in terminal VS Code:

```powershell
npm.cmd install
npm.cmd run dashboard
```

Open up `http://127.0.0.1:4180`. By default available Owen, Liam and Noah; server — Java 1.21.1, offline, `127.0.0.1:25565`.

1. Select the agent in the left column and press **Connect**.
2. In the tab **Challenges** Pick a template and press **+ Task**.
3. Change name, Options, order of buttons ↑/↓. Remove the unnecessary blocks.
4. Press **Apply line**. Agent will stop the previous job.
5. Press **Start**. The status of each task is displayed above the editor.

tab **Code JSON** Edits the same line. It's a declarative JSON, which is checked by the panel server. For my own JavaScript-logic use the library in the application and connect Reactor/skills. The panel does not perform arbitrary JavaScript from text field.

Example of turn:

```json
[
  {
    "id": "wood",
    "title": "Collect four logs of any kind",
    "type": "scenario",
    "scenario": {
      "schemaVersion": 1,
      "name": "Wood",
      "steps": [{ "id": "logs", "type": "resources", "targets": { "#logs": 4 } }]
    }
  },
  {
    "id": "table",
    "title": "Prepare the Versac",
    "type": "action",
    "action": { "skill": "ensureStation", "args": { "station": "crafting_table" } }
  }
]
```

`id` unique inside the line. `title` — signature in panel. `action` One skill, `scenario` Checks the conditions of the steps and selects sequences. Before 32 Tasks in turn, to 64 Stages in the scenario. The format of the steps is described in [of the scenario management](SCENARIOS.md).

A successful plan is not yet complete: need a result of the performer or observation of the scenario. A single action with an error stops the line. The script lets its planner choose the alternative; after six consecutive errors, it also stops. Fix it and use the line again or press **Repeat**, then **Start**. Reuse replaces line and drops performance marks. Protection, Nutrition and other brain-based policies continue to have their own priorities.

**Inventory** shows objects and armor. **Management** allows for the designation of survival profile, transfer subject, perform manual action. **Learning** Shows the transitions, No. of weights updates and memory of failures.
