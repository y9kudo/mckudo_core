# Локальный центр агентов 0.6.0

Запуск из корня проекта:

```powershell
npm.cmd run dashboard
```

Панель: `http://127.0.0.1:4180`. Выбери Owen, Liam или Noah в колонке команды, подключи к серверу и назначь очередь во вкладке «Задачи». «Начать» запускает мозг; «Пауза» останавливает текущую работу; «Возродить» доступно погибшему агенту.

- **Задачи:** добавление шаблонов, изменение параметров и порядка; блоки и JSON представляют одну очередь. «Применить очередь» останавливает прежнюю работу и сбрасывает её прогресс.
- **Инвентарь:** реальные слоты, количество и надетое снаряжение.
- **Обучение:** число переходов, обновления весов, ошибка модели и последние исходы движения.
- **Управление:** профиль выживания, передача предмета, ручные навыки KudoConnect.

JSON — проверяемый формат данных, а не произвольный исполняемый JavaScript. Обычные действия завершаются подтверждением исполнителя. Сценарии проверяют условия этапов и могут выбрать другой путь после неудачного действия. После шести последовательных ошибок сценарий останавливается для проверки; кнопка «Повторить» возвращает задачу к работе.

Панель сохраняет очередь, завершённые задачи и веса модели в `data/agents/`, отдельно для каждого мира и имени. Приложение привязано к loopback, команды защищены токеном текущего процесса и проверкой Origin/Host. Токен хранится только в текущей странице. Для другого мира задай `MC_WORLD` перед запуском.
