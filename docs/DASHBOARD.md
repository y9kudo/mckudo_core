# Локальный центр агентов

Из корня `mckudo_core` запусти:

```powershell
npm.cmd run dashboard
```

Открой **http://127.0.0.1:4180**. Панель запускается отдельно от подключения команды. Кнопка «Подключить команду» вводит трёх агентов на сервер; «Начать» запускает выбранную цель. Имена по умолчанию — Owen, Liam, Noah.

Карточки показывают здоровье, голод, координаты, причину решения и ошибки. Справа доступен инвентарь с реальными номерами слотов и количеством. Внизу — последние события. Обновление раз в секунду.

| Управление | Результат |
| --- | --- |
| Подключить / Выйти | Открыть / закрыть игровую сессию |
| Начать / Пауза | Запустить мозг / отменить текущее действие и остановить автоматизацию |
| Возродить | Запросить серверное возрождение погибшего агента |
| Назначить цель | Остановить прежний мозг и сохранить новую цель; затем нажми «Начать» |
| Крафт | Создать указанное число новых предметов; материалы должны быть доступны |
| Подарить 1 | Встреча и подтверждённая передача одного предмета другому агенту |
| Своё действие | JSON с `skill` и `args` из контракта KudoConnect |

Ручные действия ставят автоматическое поведение на паузу. Возрождение не возвращает потерянные предметы и не включает мозг автоматически. Крафт, строительство и передача изменяют игровой мир обычными действиями клиента.

`MC_HOST`, `MC_PORT`, `MC_WORLD`, `MC_DASHBOARD_PORT` меняют адрес Minecraft, порт, имя мира и порт панели. Если запускаешь собственную команду, передай её менеджер в `startDashboard({ manager })`, чтобы панель управляла теми же экземплярами. Нельзя одновременно подключить вторую сессию с теми же именами во время игрового теста.

В инвентаре отдельно отмечены надетые шлем, нагрудник, поножи и ботинки. Переносимые предметы и надетая броня получены из разных серверных слотов. Состояние клиента также содержит время мира и признак сна.

Панель слушает только `127.0.0.1`, проверяет адрес/Origin и токен сессии для команд. Это локальный инструмент управления; удалённый вход и многопользовательские роли не реализованы. Автор — **y9kudo**, MCKudo Core 0.4.0.
