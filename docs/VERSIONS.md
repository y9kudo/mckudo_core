# Версии Minecraft и KudoConnect

Совместимость проверяется отдельно для данных игры, транспорта и исполнителя. Один поддерживаемый номер протокола в зависимости не гарантирует работу физики, окон, инвентаря и действий KudoConnect.

| Профиль | Каталог | Нативный клиент | Проверка на настоящем сервере |
|---|---|---|---|
| Java 1.21.1 | Доступен | Доступен, offline | Прогоны 0.5.0, подъёма/спуска и короткой очереди с обучением 0.6.0 |
| Java 1.21 | Доступен | Включён общий профиль протокола 767 | Отдельного игрового прогона нет |
| Другие версии 1.7–26.1 | Зависит от установленного `minecraft-data` | Нужны игровые адаптеры | Не заявлена |
| Java 26.3 | Метаданные номера есть; нужного полного каталога в установленной зависимости нет | Нет | Нет |

```js
import { listVersionSupport, versionSupport } from './kudoconnect/index.js';
console.table(listVersionSupport());
console.log(versionSupport('26.3'));
```

`listVersionSupport()` — лёгкий список без разворачивания каталогов всех версий. `versionSupport(version)` по явному запросу проверяет конкретную версию: `known`, `protocol`, `catalog`, `transport`, `native`, `liveTested`. `liveTested` означает наличие предыдущего игрового прогона профиля, а не сертификацию всех функций текущего изменения.

Текущий KudoConnect принимает `version: '1.21'` или `'1.21.1'`. Остальные значения отклоняются понятной ошибкой до подключения. Поддержка диапазона от 26.3 до старых версий остаётся задачей развития платформы; фиктивного переключателя «все версии» нет.

Для нового профиля необходимо проверить кодирование пакетов, загрузку чанков и диапазон высот, компоненты предметов, слоты окон и подтверждения действий, рецепты, метаданные сущностей и физику. После этого нужны регрессионные и игровые проверки. Обновление `minecraft-protocol` само по себе не заменяет эту работу.

Источники зависимостей: [поддержка транспорта](https://github.com/PrismarineJS/node-minecraft-protocol/blob/master/docs/README.md), [данные Minecraft](https://github.com/PrismarineJS/minecraft-data). [Java 26.3](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3) выпущена; доступность версии игры и готовность адаптера — разные условия.
