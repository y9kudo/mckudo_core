**OMConnect 0.7.0** — Self-contained library Minecraft Java: connection, Peace observation, physics and agents. Author **y9kudo**, **MIT**. Mineflayer and OvermindMC not required for installation and execution of the client.

### What added

- OMVectorize: Large-scale waterways, Air reserve, A pro-Elitist and limited air corridor. The flight attendant checks the elites, Missile, server metadata and landing.
- Creative-Flight, Collection of items with state properties, Piece of paper, and flower in pot.
- Search for storage/panels, carry-over of assigned amount, Signature of the repository with server check NBT.
- Ladies, Prognosis of a dangerous fall, Water attempt/Pearl, Protection of intermediate angles of look from provocation of endermen.

- Microsoft Device Code Auth, server reading GUI and confirmed landing/exit from transport, those who entered 0.7-dev.
