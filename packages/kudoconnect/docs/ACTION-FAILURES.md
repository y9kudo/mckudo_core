# Ошибки действий

Автор: y9kudo. API версии 0.7.0; старый архив `dev.0` его не содержит.

Сообщение ошибки предназначено для человека, `code` — для программы. Не выбирайте стратегию по наличию слова «маршрут» в сообщении.

```js
import { KudoActionError } from 'kudoconnect';

try {
  await client.execute({ skill: 'navigate', args: { x: 10, y: 64, z: 5 } });
} catch (error) {
  if (error instanceof KudoActionError) {
    console.log(error.code, error.evidence);
  } else {
    throw error; // Отмена, разрыв соединения и другие ошибки сохраняют свой смысл.
  }
}
```

| Код | Значение |
|---|---|
| `START_UNSUPPORTED` | Наземный планировщик не подтвердил свободное место у ног/головы и полную опору |
| `NO_PATH` | В наблюдаемой области с текущими правилами путь не найден |
| `SEARCH_BUDGET` | Поиск исчерпал бюджет узлов |
| `STALE_WORLD` | Начальная позиция изменилась во время планирования |
| `STEP_STALLED` | Истёк бюджет исполнения шага |
| `OCCUPIED` | Не удалось освободить проход или обойти игроков за ограниченное число перепланирований |
| `SERVER_CORRECTION` | Сервер несколько раз исправил положение агента |
| `SUPPORT_CHANGED` | Проход или опора изменились при выполнении маршрута |
| `ACTION_FAILED` | Неуточнённая ошибка |

`planRoute()` и `planRouteAsync()` возвращают `failure` у отклонённого маршрута. Исполнитель `navigate` преобразует этот результат в `KudoActionError`. Старые и другие навыки могут продолжать возвращать обычные ошибки; отмена не превращается в доказательство недостижимости.

Для `START_UNSUPPORTED` поле `evidence` содержит `complete` и карту скалярных фактов: положение ног, режим `ground` и прочитанные блоки. `blockEvidenceValue(block)` возвращает сравнимую строку состояния/форм, для неизвестного блока — `null`. Факты привязаны к версии мира; сравнивать ID разных версий нельзя.

`complete=false` означает, что неизвестный блок помешал проверке. Такая запись не доказывает наличие препятствия. Даже `complete=true` подтверждает отказ текущей наземной модели, а не универсальную физическую невозможность действия.

Сведения о переполнении бюджета, соседних игроках и серверной коррекции не являются постоянным запретом на действие. Срок ожидания, повторная проверка и обмен опытом относятся к приложению или мозгу агента.
