# Страховка при падении

KudoConnect 0.7 включает страховку по умолчанию. Во время падения клиент прогнозирует место приземления только по загруженным блокам. Если опора известна и высота опасна, он пытается разлить воду и затем забрать её. При угрозе пустоты или сильном боковом сносе в Энде он ищет широкую наблюдаемую площадку и рассчитывает бросок жемчуга Края. Аварийное действие прерывает обычную навигацию; ресурсы должны уже быть в инвентаре.

```js
import {createKudoConnect} from 'kudoconnect';

const client=createKudoConnect({
  host:'127.0.0.1',port:25565,username:'Avery07',
  version:'1.21.1',auth:'offline',fallSafety:true
});
client.on('fallRescue',event=>console.log(event.phase,event.skill,event));
await client.connect();
```

Событие `planned` означает выбор действия, `dispatched` — успешную отправку команды и её частичное подтверждение, `failed` — отказ. Для жемчуга `thrown:true` подтверждает расход предмета сервером, но `landingConfirmed:false` означает, что успешную телепортацию нужно проверить отдельно по позиции. Для воды `recovered:true` означает, что ведро снова наполнено по изменению серверного инвентаря.

Ручной вызов навыков доступен через `client.execute({skill:'waterClutch'})` и `client.execute({skill:'escapePearl'})`. План можно проверить до исполнения через `predictFallLanding`, `planPearlEscape` и `decideFallRescue`. При неизвестных чанках, отсутствии широкой площадки, слишком сильном сносе, задержке сети или запрете установки блоков спасение не гарантируется. Вода не спасает от пустоты. Если приложение само управляет падением, автоматический обработчик можно отключить опцией `fallSafety:false`.
