# Защита построек

Создатель: **y9kudo**. Модуль работает самостоятельно внутри KudoConnect.

```js
import { createKudoConnect } from 'kudoconnect';

const client = createKudoConnect({
  username: 'Harper', host: '127.0.0.1', port: 25565,
  version: '1.21.1', auth: 'offline',
  protection: { regions: [{
    id: 'home', dimension: 'minecraft:overworld',
    min: { x: 10, y: 60, z: 20 },
    max: { x: 30, y: 90, z: 40 }
  }] }
});

await client.connect();
client.on('protectedEdit', e => console.log(e.operation, e.position, e.reason));
```

Замените углы на координаты своего дома, включая крышу и подвал. Границы включаются в объём, дробные координаты округляются вниз. Ходьба внутри разрешена, добыча и постановка запрещены. До 128 областей. `client.protection.add(region)` добавляет или заменяет область по ID, `remove(id)` удаляет, `regions` возвращает копию. Сохраняйте конфигурацию сами для следующего подключения; у каждого клиента своя политика.

По умолчанию `structures:true`, `structureRadius:2`. Доски, булыжник, кирпичи, двери, стекло и функциональные блоки защищены как признаки постройки; соседние природные блоки в этом радиусе тоже не добываются. Листва, брёвна и руды сами по себе не являются признаками дома. Такая эвристика не определяет владельца и может сохранять природные структуры. Дом из природных материалов следует защищать явной областью.

`structures:false` отключает только эвристику; области продолжают работать. `structureRadius` — целое число 0–3. Подтверждённые собственные установки можно разбирать вне областей; до 4096 записей, серверное обновление отменяет запись. Эта память принадлежит текущему экземпляру клиента.

Встроенные `dig`, `gather`, расчистка `navigate`, `place`, мосты, `pillar`, `descendPillar`, установка кровати и изменения порталов проверяют защиту. `excavate:true` не даёт обхода запрета. Проверки повторяются после поворота и перед завершением добычи. Уже обработанный сервером пакет отменить невозможно. Чтение сундука и использование кровати не являются добычей/постановкой и регулируются приложением отдельно.

Для собственного навыка, который напрямую пишет пакеты:

```js
const decision = client.protection.check({
  operation: 'dig', dimension: client.state.dimension,
  position: { x: 15, y: 64, z: 25 },
  getBlock: p => client.world.blockAt(p)
});
if (!decision.allowed) throw new Error(decision.reason);
```

`KudoProtection` и `isStructureBlock` экспортированы для внешнего планировщика. Чистые `planRoute` / `planRouteAsync` не привязаны к клиенту: передавайте `canDig(block,position)` и `canPlace(position)` для собственной политики. Это ограничение клиента, а не серверная защита от чужих игроков или пользовательских сетевых навыков.
