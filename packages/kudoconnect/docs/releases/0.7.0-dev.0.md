KudoConnect — самостоятельная библиотека подключения и управления Minecraft Java. Автор **y9kudo**, MIT. Mineflayer и MCKudo для запуска клиента не требуются.

**Предварительная версия 0.7.0-dev.0**, стабильный релиз остаётся 0.6.0.

- **KudoVectorize**: проверка объёма тела, асинхронные водные маршруты в 3D, коллизии и запас воздуха; математический предиктор элитр. Импорт `kudoconnect/vectorize`.
- Исполнитель плавания обычными игровыми управлениями с отменой, бюджетом времени и проверкой изменившегося пути.
- Microsoft Device Code авторизация через `minecraft-protocol`/`prismarine-auth`, отдельный кеш и безопасные события состояния. Offline-вход сохраняется.
- Наблюдение пользовательских GUI: заголовки, названия и описания предметов, уникальные селекторы, ревизии окна и наблюдение ответа сервера.
- Посадка в лодки/вагонетки и выход по серверному подтверждению пассажиров. Состояние транспорта в снимке клиента; пешие действия во время поездки блокируются.
- Типы API, самостоятельные примеры входа и документация новых модулей.

Релиз создаётся только после тестов Windows/Linux × Node.js 22/24. В составе MCKudo локально прошли 355 тестов, строгая проверка TypeScript и установка обоих архивов в отдельное приложение. Реальный offline Java 1.21.1 подтвердил подключение, короткий наземный маршрут без коррекций и расчёт водного пути; выполнение плавания в игровом сервере этим прогоном не проверялось.

Настоящий Microsoft-вход и Realms ещё не испытаны. Поддерживаемые нативные профили — Java 1.21/1.21.1; не заявляется совместимость с текущей версией Realms. Автопилот элитр, управление лодкой и железнодорожная навигация ещё не реализованы. Наблюдаемый ответ GUI не гарантирует выполнение выбранной серверной команды. Полное автономное прохождение Minecraft не подтверждено.
