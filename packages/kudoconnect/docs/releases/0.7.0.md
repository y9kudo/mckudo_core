**KudoConnect 0.7.0** — самостоятельная библиотека Minecraft Java: соединение, наблюдение мира, физика и действия агентов. Автор **y9kudo**, **MIT**. Mineflayer и MCKudo не нужны для установки и выполнения клиента.

### Что добавлено

- KudoVectorize: объёмные водные маршруты, запас воздуха, предиктор элитр и ограниченный воздушный коридор. Исполнитель полёта проверяет элитры, ракету, метаданные сервера и посадку.
- Creative-полёт, получение предметов со свойствами состояния, поштучная постановка блоков и цветка в горшок.
- Поиск хранилищ/табличек, перенос заданного количества, подпись хранилища с проверкой серверного NBT.
- Лестницы, прогноз опасного падения, попытка воды/жемчуга, защита промежуточных углов взгляда от провокации эндерменов.
- Ближняя фаза сидящего дракона с обращением к голове и подтверждением урона; финальное уточнение прицела по движущейся цели.
- Структурированные ошибки движения `KudoActionError` и наблюдения для перепроверки стартового предусловия.
- Исправления подбора, выбора инструмента и переключения резервного каталога на серверную книгу рецептов.
- Microsoft Device Code Auth, чтение серверных GUI и подтверждённая посадка/выход из транспорта, вошедшие из 0.7-dev.

### Проверки и ограничения

Нативные профили: **Java 1.21 / 1.21.1**. Java 26.3 остаётся экспериментом и не объявляется поддержанной. Настоящий Microsoft-вход, полное управление транспортом и автономное прохождение игры требуют отдельных испытаний. В интеграции с MCKudo локально прошли **436 тестов**, TypeScript и установка обоих архивов без Mineflayer. CI этого репозитория отдельно проверяет клиент на Windows/Linux × Node 22/24 перед публикацией.

Полёт, сортировка и бой с драконом проверялись в подготовленных сценариях. Полное прохождение с нуля не подтверждено; последний командный алмазный сценарий не достиг цели.

### Установка

```powershell
npm.cmd install .\kudoconnect-0.7.0.tgz
```

Скачайте архив и `SHA256SUMS.txt` из Assets. Требуется Node.js 22+. Публикации в npm нет; кэш OAuth и локальное состояние не включаются.
