KudoConnect — самостоятельная библиотека подключения и управления Minecraft Java. Автор **y9kudo**, MIT. Mineflayer и MCKudo не нужны для выполнения клиента.

- Асинхронный A* с общим ограниченным планировщиком, отменой и проверкой актуальности чанков.
- Мосты с приседанием и подтверждением расхода блоков, строительство под ногами и спуск по своему столбу.
- Защита построек/областей, боевой обход, щит и восстановление оружия, проверка видимости.
- Подтверждённый подбор предметов, ленивые реестры и книга рецептов сервера, незеритовое улучшение.
- Группы до 20 клиентов с обменом данными вне чата, внимание к игрокам, прогноз пересечения маршрутов.
- Отдельный пакет, типы, документация и автоматические тесты; Windows/Linux × Node.js 22/24 проверяются до создания релиза.

Проверенный игровой профиль — **offline Java 1.21.1**; для 1.21 включён профиль, отдельный игровой прогон ещё нужен. Поддержка всех версий не заявляется.
