# Серверные меню и транспорт

## Чтение GUI

Сервер может открыть меню самостоятельно. KudoConnect сохраняет это окно вместо немедленного закрытия. `client.menu()` возвращает заголовок, тип, состояние готовности, ревизию и верхние слоты: ID предмета, количество, имя и lore. Поля текста и NBT обрабатываются как данные.

```js
import {findMenuSlot} from 'kudoconnect';

await client.waitFor(()=>client.menu()?.ready,{event:'container',timeoutMs:10000});
const choice=findMenuSlot(client.menu(),{contains:'Выживание'});
const result=await client.execute({skill:'menuClick',args:{
  windowId:choice.windowId,revision:choice.revision,slot:choice.slot
}});
console.log(result.responseObserved,result.menuChanged);
```

`findMenuSlot` требует единственного совпадения. Можно использовать `item`, точное `name`, подстроку `contains` или номер `slot`; несколько полей применяются совместно. Пустой или неоднозначный запрос отклоняется. Переводимые компоненты сохраняют ключ перевода, если сервер не прислал буквальный текст.

Клик проверяет, что окно и ревизия остались прежними и курсор пуст. Новые данные окна или его закрытие подтверждают **ответ сервера**. `menuChanged: false` означает, что пришла только синхронизация: это не доказательство входа в выбранный режим. Результат режима проверяйте отдельным игровым наблюдением. Без ответа за 4 секунды действие завершается ошибкой.

Неизвестные типы с совместимой структурой верхних слотов + 36 слотов игрока можно прочитать. Они не получают свойства верстака/печи. Меню, полностью нарисованное в клиентском моде без пакетов контейнера, требует отдельного адаптера.

## Посадка и выход

```js
await client.execute({skill:'mount',args:{entityId:'42'}});
console.log(client.vehicle());
await client.execute({skill:'dismount'});
```

Транспорт должен быть реально наблюдаемой лодкой или пассажирской вагонеткой в пределах 3 блоков. Посадка считается выполненной после серверного `set_passengers`, а выход — после удаления пассажира. Пока игрок сидит, обычная пешая физика не применяется; положение следует за наблюдаемой сущностью транспорта. Уничтожение транспорта, возрождение и смена измерения очищают привязку. Пешие и боевые действия требуют сначала выйти.

В 0.7-dev это механизм посадки/наблюдения/выхода. Автоматическое руление лодкой, поиск железнодорожного маршрута и ускорение транспорта пока не реализованы. Подтверждение посадки проверено протокольными тестами; отдельный игровой тест лодки и вагонетки ещё нужен.
